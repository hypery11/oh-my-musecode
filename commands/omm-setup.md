# /omm-setup

Help the user install Oh My Muse Code into Muse.

## Steps
1. Read skill `document-specialist` if you need tone help.
2. Print install/approve commands using `MUSE_EXPERIMENTAL_PLUGINS=1`.
3. Explain validate-before-approve: `muse plugins validate <path> --json`.
4. Write `.omm/setup-notes.md` with the exact commands you recommended.
5. Remind: experimental plugins flag required on 1.0.1-R2006.1.

Do not run install into the user’s Muse home unless they explicitly ask.
