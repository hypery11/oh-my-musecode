# Support

- Bugs and features: GitHub Issues
- Questions: GitHub Discussions
- Agent / contributor rules: [AGENTS.md](AGENTS.md)
- Feature completeness (honest): [docs/FEATURE-MATRIX.md](docs/FEATURE-MATRIX.md) (added as the matrix lands)

Muse 1.3.0 plugin APIs are experimental. You need `MUSE_EXPERIMENTAL_PLUGINS=1`. After hook source changes, run `muse plugins approve oh-my-musecode` again.

Do not expect live tmux HUD, remote ask transport, or 1:1 Claude/Codex parity.
